privacy

gronka keeps no record of who you are or what you download. we are not interested in spying on anyone; we keep only what it takes to keep the service working. this page covers gronka.dev, api.gronka.dev and the gronka discord bot.

no request logs, no download history, no analytics, ads, trackers or cookies. when something breaks, the server prints an error line with links, ip addresses and keys stripped out, into a small buffer that overwrites itself. a few counters (downloads per site) live in memory and reset on every restart.

when a request fails, the link, the error and which download steps were tried are kept for up to 7 days so the failure can be fixed. nothing is kept for requests that succeed, and no user, server or channel ids are kept. while a discord request runs, the bot holds a handle for its reply (which channel to answer in); it is deleted the moment the request ends.

to stop one person hogging the server, requests are counted per ip address for 10 minutes, as a keyed hash in memory under a key that changes daily, never the address itself.

a file reaches you straight from the site (the site sees your ip address), streamed through dl.gronka.dev (stored nowhere, the link dies after an hour), or as a copy on cdn.gronka.dev under a random name, deleted after an hour. gronka's working copy is deleted as soon as the file is ready.

there are no accounts. an api key is stored only as a keyed hash, with no date, name or email. revoking it deletes it.

gronka runs behind cloudflare, which also runs the turnstile check on the page; cloudflare's privacy policy covers what they see.

the discord bot

each command run bumps an anonymous counter for that command, with no user, server or channel id; /info shows the totals. failures are kept as described above.

your media is processed in a temporary folder and deleted as soon as the result is delivered. a result too big to attach on discord goes to cdn.gronka.dev under a random link that anyone holding it can open, deleted within three days.

the bot does not read your server's messages. discord only shows it messages that mention it, direct messages, and the message you run a command on. message text is never stored or logged, and nothing about servers or channels is kept once a request ends.

we sell or share nothing. gronka is not meant for anyone under 13. questions: gronkasupport@proton.me.
