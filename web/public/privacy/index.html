privacy

gronka keeps no record of who you are or what you download. we are not interested in spying on anyone; we keep only what it takes to keep the service working. this page covers web.gronka.dev and api.gronka.dev. the discord bot has its own policy.

no request logs, no download history, no analytics, ads, trackers or cookies. when something breaks, the server prints an error line with links, ip addresses and keys stripped out, into a small buffer that overwrites itself. a few counters (downloads per site) live in memory and reset on every restart.

to stop one person hogging the server, requests are counted per ip address for 10 minutes, as a keyed hash in memory under a key that changes daily, never the address itself.

a file reaches you straight from the site (the site sees your ip address), streamed through dl.gronka.dev (stored nowhere, the link dies after an hour), or as a copy on cdn.gronka.dev under a random name, deleted after an hour. gronka's working copy is deleted as soon as the file is ready.

there are no accounts. an api key is stored only as a keyed hash, with no date, name or email. revoking it deletes it.

gronka runs behind cloudflare, which also runs the turnstile check on the page; cloudflare's privacy policy covers what they see.
